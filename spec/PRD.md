# PRD — Vocabulary Level Learning App

## Problem
When reading books/articles, encountering many unknown words is demotivating.
User wants a structured way to identify unknown/forgotten words by level (A1–C2) and learn them systematically.

## Target User
- Primary: Single user (the creator) learning English
- Secondary: Admin role (for dataset control and management)

## Goals
- Determine gaps for a selected level (e.g., B2)
- Learn words efficiently using structured sessions
- Track what is Known vs Learning vs Forgotten
- Review forgotten words regularly

## Non-goals (MVP)
- Social features
- Complex gamification
- Paid subscriptions
- Offline-first perfection (we’ll add later)

## MVP Features
1) Auth (Email)
2) Choose target level (A1…C2)
3) Learning sessions (flashcards)
4) Word state tracking: Known / Learning / Forgotten
5) Review mode for Forgotten
6) Progress dashboard by level

## Success Metrics (Personal)
- Daily session completed (yes/no)
- Words reviewed per day
- Forgotten words decreasing over time
